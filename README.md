# 🚀 Simulata - מערכת ניהול סימולציות
### 📝 רקע על הפרויקט
מערכת זו נבנתה כחלק מפלטפורמת **Simulata**. מטרת הפרויקט היא לספק למשתמשים (כמו מנהלי רשתות או מפתחי מערכות) ממשק גרפי נוח, חכם ואינטואיטיבי להקמה וכיול של סימולציות רשת מורכבות. 

במקום להסתבך עם קבצי קונפיגורציה ארוכים או פקודות טרמינל, המשתמש יכול לבחור מערכות, לשייך אליהן חוזים ופרוטוקולים (כמו ABC), להגדיר מי הרכיבים שיכתבו מידע (Writers) ומי יקראו אותו (Readers), ולדמות ערוצי תקשורת אמיתיים כולל מגבלות רשת (כמו השהיות ואיבוד מידע). המערכת מוודאת שהנתונים תקינים, ויוצרת קובץ סימולציה מוכן להרצה בלחיצת כפתור.

פלטפורמה מתקדמת להקמה, ניהול ועריכה של סימולציות תקשורת בין מערכות, המבוססת על **React**, **TypeScript** ו-**Tailwind CSS**. המערכת מאפשרת הגדרה מדויקת של טופולוגיית רשת, חוזים, רכיבי קצה ופרמטרים של ערוצי תקשורת.

---

## ✨ פיצ'רים מרכזיים במערכת

* **⚡ טופולוגיית רשת דינמית:** חיבור וקישור חכם בין מערכות, חוזים וגרסאות פרוטוקול ABC בזמן אמת.
* **🛠️ ניהול רכיבים (Entities):** שליטה מלאה בפרמטרים של רכיבי כתיבה (Writers) ורכיבי קריאה (Readers).
* **📡 כיול ערוצי תקשורת:** הגדרה מדויקת של השהיה (Latency) וג'יטר (Jitter) לסימולציה מציאותית.
* **🔔 מערכת התראות גלובלית (Toasts):** חיווי מיידי ואינטראקטיבי על הצלחת פעולות או שגיאות במערכת.
* **🎨 פלטת צבעים מותאמת:** שימוש מדויק בצבעי הצי והבסיס של המערכת (`navy` ו-`midnight`) מתוך הפיגמה.

---

## 💻 טכנולוגיות פיתוח

* **ספריה ראשית:** React (שימוש ב-Context API וב-Hooks)
* **שפה:** TypeScript (עבודה עם Types קשיחים מול ה-API)
* **עיצוב ואנימציות:** Tailwind CSS (אנימציות Slide-in מותאמות)
* **אייקונים:** Lucide React
